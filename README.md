# Resurskollen - full kontroll, mindre krångel

**Resurskollen** är den smarta lösningen för dig som driver ett litet till medelstort företag, Med ett enkelt och kraftfullt gränssnitt hjälper appen dig att hålla ordning på det som verkligen räknas 
**kunder, personal, jobb och ekonomi.** </br></br>

- [x] **Kunder** - samla all kundinformation på ett ställe, snabbt tillgängligt när du behöver det.
- [x] **Jobb** - planera, tilldela och följa upp dina uppdrag med full översikt
- [x] **Personal** - se vem som gör vad, när och var – och optimera bemanningen.
- [x] **Ekonomi** - få insikt i intäkter och kostnader så du alltid har kontroll på läget.

 </br><br>
 Med Resurskollen slipper du krångliga system, lappar och gissningar. Oavsett om du är ensamföretagare eller driver ett team, så ger Resurskollen dig verktygen för att jobba smartare – inte hårdare.

 </br></br>
